Kết nối với website

Dashboard đăng bài bằng cách lưu thẳng vào kho mã GitHub của tritravel.vn. Bạn chỉ cần tạo một “khoá truy cập” (token) một lần cho mỗi thiết bị.

Cách tạo token (2 phút)
  1. Đăng nhập GitHub, mở Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: chọn Only select repositories → tritravel.
  3. Permissions → Repository permissions → Contents: chọn Read and write. Các quyền khác để nguyên.
  4. Bấm Generate token, sao chép chuỗi github_pat_… và dán vào ô bên dưới.
Token chỉ lưu trong trình duyệt của bạn trên máy này, không gửi đi đâu ngoài GitHub. Đừng đăng nhập trên máy công cộng.
